# AstrBot 消息防抖插件 (`astrbot_plugin_message_debouncing`)

一款专为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 设计的**智能消息防抖插件**。

解决用户在聊天中习惯连续分段发送多句话（例如先发“在吗”，再发“帮我写个故事”，再发“主角叫小明”），导致机器人多次触发 LLM 并产生碎片化回复的问题。

---

## ✨ 核心特性

- ⏱️ **智能等待与重置倒计时**：
  当检测到消息需要进行 LLM 对话时，先暂停等待指定时长（默认 5s）。若在此期间收到用户后续发言，自动重新倒计时 5s。
- 📦 **原生多模态聚合**：
  倒计时结束后，将收集到的所有消息（文本、图片、语音、文件等）合并为一条完整消息，无缝交由 AstrBot 的 LLM 处理链路。**无需插件手动区分或转码图片/文字/语音**，完全复用 AstrBot 原生多模态解析能力。
- 👥 **群聊每用户独立计时**：
  在群聊中，针对**每一个触发 LLM 对话的用户**进行完全独立的倒计时与消息缓冲。多名用户同时与机器人对话时互不干扰。
- 🎛️ **灵活的独立开关**：
  - 支持**私聊防抖开关**（可独立开启/关闭）。
  - 支持**群聊防抖开关**（可独立开启/关闭）。
  - 支持自定义**防抖等待时间**（默认为 5.0 秒，可在 WebUI 中拖动滑动条调节）。
- ⚡ **指令穿透保护**：
  在防抖等待期间，如果用户发送了指令（如 `/help`、`/reset` 等），插件会自动释放当前防抖任务，并让指令正常优先执行，避免指令被误当做普通文本喂给大模型。

---

## ⚙️ 配置说明

在 AstrBot 管理面板（WebUI）的插件配置中，可直接调整以下参数：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `debounce_seconds` | `float` | `5.0` | 防抖等待时间（秒）。倒计时内收到新消息将重置该时间（支持 1~60 秒范围滑动条调节）。 |
| `enable_private` | `bool` | `true` | 是否在**私聊**场景中启用消息防抖。 |
| `enable_group` | `bool` | `true` | 是否在**群聊**场景中启用消息防抖（群内各用户独立计时）。 |

## 🚀 工作流程

```text
[用户发送第 1 句话]
       │
       ▼
[AstrBot 管道识别需要调用 LLM]
       │
       ▼
[触发 debounce_waiting_llm 钩子] ──> 启动 5s 倒计时 (Key: platform:group:user)
       │
       ├──── 在 5s 内收到第 2 句话/图片/语音 ──> [intercept_follow_up 捕获并重置倒计时为 5s]
       │
       ├──── 在 5s 内收到第 3 句话 ─────────> [intercept_follow_up 捕获并重置倒计时为 5s]
       │
       ▼
[5s 内未再收到新消息 (超时)]
       │
       ▼
[合并所有文本与消息段 (Plain/Image/Record/File)]
       │
       ▼
[交由 AstrBot 原生 LLM 链路处理] ──> 用户收到包含所有上下文的单次完整回复
```

## 📦 安装与使用

1. 将本插件目录放入 AstrBot 的插件目录：
   ```bash
   cd AstrBot/data/plugins/
   git clone https://github.com/cyilin36/astrbot_plugin_message_debouncing.git
   ```
2. 重启 AstrBot 或在 WebUI 的插件页面点击「重新加载插件」。
3. 在 WebUI 的插件配置中，按需调整防抖时间及私聊/群聊开关。
